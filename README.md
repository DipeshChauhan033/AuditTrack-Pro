# Audit Stack Visit

Audit Stack Visit is a web-based Company Audit Visit Management System designed to help banks, auditors, and CA teams manage company audit visits, stock verification, audit reports, photo documentation, and review processes through a centralized platform.

## Live Demo

https://audit-stack-visit.lovable.app

---

## Project Overview

This application digitizes the traditional company audit process by providing a structured workflow for:

* Company Management
* Audit Visit Management
* Stock Verification
* Inventory Checking
* Audit Report Submission
* Photo Documentation
* CA Review Process
* Audit Assistant Chatbot

The system helps improve audit efficiency, transparency, and record management.
